# 翻訳（i18n）の決まり / How translations work

tech-network を世界のたくさんの言語で読めるようにする（S-063）。**全部 CC0**。**日本語が正**（元の文）。訳が無い所は 英語 → 日本語 の順に出る。

## ファイル
| ファイル | 中身 | だれが作る |
|---|---|---|
| `docs/i18n/source.json` | 訳す元の文。キーごとに日本語（`ja`、正）と、あれば今の英語（`en`） | `python tools/i18n_export.py`（手で直さない） |
| `docs/i18n/<言語コード>.json` | ある言語の訳。キーは source.json と同じ | 翻訳する人（機械訳でもよい、印を付ける） |
| `docs/lang/<言語コード>.json` | ページが読む形（ネットワーク担当が i18n から作る） | ネットワーク担当 |

最初の言語：`en`・`zh-Hans`・`es`・`hi`・`ar`（右から左）・`pt`・`fr`・`ru`・`id`・`ko`（BCP 47 の言語コード）

## キーの付け方
| キー | 中身 |
|---|---|
| `<ノード番号>.name` | 物・技術・発見の名前（例 `9-23.name` ＝ MOSFET） |
| `<ノード番号>.hee1` | へえ①：子ども向けの一言（いちばん大事） |
| `<ノード番号>.hee2`〜`hee4` | へえ②学生・③大人・④ガチ |
| `<ノード番号>.real` | 本当の歴史（年・人・しくみ） |
| `<ノード番号>.play` | ゲームでの遊び方 |
| `person.<ノード番号>.<何番目>.intro` | 人物の紹介（故人だけ） |
| `term.<用語>.name`・`term.<用語>.def` | 用語集の名前と説明 |
| `ui.<名前>` | 画面の文（ボタン・見出し） |

## 言語のファイルの形（`docs/i18n/<言語コード>.json`）
```json
{
  "_meta": {
    "lang": "es",
    "name": "Español",
    "dir": "ltr",
    "machine": true,
    "translator": "AI (Claude) + だれが見たか",
    "source_checked": "2026-10-26",
    "notes": "気になった所"
  },
  "strings": {
    "9-23.name": "MOSFET",
    "9-23.hee1": "De todas las cosas que ha fabricado la humanidad, el MOSFET es la más numerosa.",
    "ui.film": "▶ Cómo se hizo"
  }
}
```
- `dir`：右から左の言語（アラビア語 `ar` など）は `"rtl"`
- `machine`：機械訳なら `true`（ページに「機械訳」の印と「訳を直す」ボタンが出る）。人が確かめたら `false`
- 訳せないキー・まだのキーは**入れない**（英語→日本語にもどる）。空の文字列も入れない

## 訳すときの決まり
1. **子ども向けのやさしい文**で（へえ①はとくに。短く、むずかしいことばを使わない）
2. **事実を足さない・変えない**。年・数・単位・化学式・`[9-23]` のようなノード番号・`H2O` のような式・URL は**そのまま**
3. 人の名前は、その言語でふつうに書く形（ラテン文字の名前はそのまま、日本人の名前はその言語の書き方）
4. **存命の人の名前を足さない**、**危ない物の作り方（手順・量・条件）を足さない**（元の文にも入れない決まり）
5. 元の文がおかしいと思ったら、訳さずに `_meta.notes` か Issue で知らせる
6. ライセンスは CC0（出典を書かなくても、だれでも使える）

## 訳を直したい人へ
- GitHub の Issue（「訳を直す」ボタンから、言語とキーが入った状態で開く）か、`docs/i18n/<言語コード>.json` を直す Pull Request で
- 元の文（日本語）が変わると `source.json` も変わる。変わったキーは、もう一度訳す（`tools/i18n_export.py` の書き出しを比べる）

## English summary
- `docs/i18n/source.json` holds every translatable string. Keys look like `9-23.hee1` (node 9-23, first fun fact). Values: `ja` (source of truth) and `en` (current English, if any). Generated by `tools/i18n_export.py`.
- A translation is `docs/i18n/<lang>.json` with `_meta` (`lang`, `name`, `dir` ltr/rtl, `machine` true/false, `translator`) and `strings` (same keys). Leave out keys you did not translate; pages fall back to English, then Japanese.
- Rules: simple words for children; do not add or change facts; keep years, numbers, units, formulas, node IDs like `[9-23]` and URLs as they are; never add names of living people or instructions for making dangerous things. Everything is CC0.
