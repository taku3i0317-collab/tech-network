本当の歴史

約2万年前（中国・仙人洞）、縄文土器 約1万6500年前。粘土鉱物（カオリナイト等）は約500〜600℃で結晶水が抜け、二度と水で戻らない（不可逆な脱水）

もっと読む（学生・大人・ガチ・人物・出典）

②学生 粘土玉5つで作る。たき火で30秒（野焼き）か、かまどで10秒焼くと土器になる。水バケツといっしょに作業台に置くと粘土玉5つにもどる（焼いた土器はもどらない）。

③大人 粘土は、とても細かい板のような結晶（粘土鉱物）が水をはさんで重なったもの。水があると板どうしがすべるので、こねて自由な形にできる。乾かしただけなら、水を吸ってまたやわらかくなる。

④ガチ 縄文土器の「縄文」は、生乾きの表面に縄を転がしてつけた模様。焼く前によく乾かさないと、中の水が焼くときに水蒸気になって割れる。

もっと知りたい人へ（Long Now 財団の Manual for Civilization の推薦の本）　Caveman Chemistry（Kevin M. Dunn）・Primitive Technology（David Wescott）
