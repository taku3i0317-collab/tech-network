本当の歴史

亜麻布は約9000〜1万年前（ナハル・ヘマル、層の年代は紀元前8210〜7780年）、亜麻繊維自体は約3万年前の痕跡（ズズアナ洞窟）。茎を水に浸けて腐らせ（レッティング＝ペクチンを微生物が分解）繊維を取り出す

もっと読む（学生・大人・ガチ・人物・出典）

②学生 草をこわすと、ときどき出る。耕した土に植えると亜麻が育ち、熟すと亜麻の茎2つと種がとれる。種は亜麻仁（あまに）ともいう。

③大人 亜麻の茎の皮のすぐ内側には、細長い細胞がつながった「靱皮（じんぴ）繊維」の束がある。長さ数十cmにもなる丈夫な繊維で、これをとり出して糸にしたのが亜麻布（リネン）。

④ガチ 亜麻の種をしぼった亜麻仁油は、空気にふれると固まる（乾性油）。油絵の具やリノリウム（亜麻仁油＋コルクなど。名前は linum＝亜麻 から）に使われてきた。
