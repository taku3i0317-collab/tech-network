本当の歴史

羊の家畜化は約1万年前、羊毛用の羊は紀元前4000年頃に西南アジアで現れ、南東ヨーロッパには約1000年遅れて広がった（間接証拠による）。紡錘車＝はずみ車の慣性で撚り（より）をかけ続ける

もっと読む（学生・大人・ガチ・人物・出典）

②学生 粘土玉1つで作る。たき火（30秒）かかまど（10秒）で焼くと土の紡錘車。

③大人 焼く前の粘土は、水でもどってしまう（[0-03] 土器と同じ）。紡錘車は重さが大事なので、焼いて固くしてから使う。

④ガチ 土器のかけらを丸く削って穴をあけ、紡錘車にすることもあった。
