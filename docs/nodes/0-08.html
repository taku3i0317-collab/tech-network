本当の歴史

新石器時代の磨製石斧（研いだ刃は欠けにくい。年 -9000 は新石器時代の始まりの慣例の年で、磨製石斧の始まりを示す出典はない⚠️。旧石器にもごく例外的な例があり、中欧には紀元前6千年紀半ばに現れる）、ほぞ組みの木製井戸枠 約7000年前（ドイツ・ライプツィヒ近郊、線帯文土器文化、年輪で紀元前5206〜5098年）

もっと読む（学生・大人・ガチ・人物・出典）

②学生 ハンドアックス＋砂＋水バケツ（戻る）＋棒で作る。打ち欠いたままの斧より長もちして速く切れる（耐久200、石の斧より少し速い）。火打ち石か黒曜石で直せる。

③大人 打ち欠いた刃の表面には、剥がしたあとの小さな段や傷がたくさんあり、そこからひびが広がって欠ける。砂（石英、とても硬い）と水で何時間もこすって傷を消すと、木を切っても欠けにくい刃になる。新石器時代の人はこの斧で森を切りひらき、畑と家を作った。

④ガチ ドイツ・ライプツィヒ近郊の井戸の木枠は、年輪から紀元前5206〜5098年の伐採とわかり、ほぞ組みで組まれていた。磨製石斧で板を作ったと考えられている。刃の一部だけを研いだ斧は、日本の旧石器時代（約3万8000年前）にも見つかっていて、世界でもかなり古い ⚠️。
