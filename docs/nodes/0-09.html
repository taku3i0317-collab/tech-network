本当の歴史

約紀元前3500年メソポタミア。現存最古級はリュブリャナ湿原の車輪（紀元前3150年頃⚠️）。ろくろ（陶工の回転台）が先行したとされる

もっと読む（学生・大人・ガチ・人物・出典）

②学生 板材3＋磨製石斧で作る（斧は戻るが少し傷む）。荷車 [0-13] に使う予定。

③大人 最初の車輪は、板をつないで円く削った重い円盤だった。転がすと、地面とこすれ合うのは車輪の外側ではなく、車軸と穴のところだけになる。だから引きずるより、ずっと小さい力で重い物を運べる。

④ガチ メソポタミアのウルクの絵文字に紀元前3500〜3350年ごろの車が描かれている。現物で最古級は、スロベニアのリュブリャナ湿原で見つかった木の車輪（紀元前3130年ごろ）⚠️ で、車輪と車軸がいっしょに回る作りだった。
