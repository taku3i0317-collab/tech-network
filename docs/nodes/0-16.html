本当の歴史

海水（塩分約3.5%）を砂に撒いて天日で濃くし（揚げ浜式・入浜式）、かん水を釜で煮詰めると NaCl が先に結晶する。残った母液が「にがり（苦汁）」＝ MgCl2 が主成分（ほかに MgSO4・KCl）。日本では縄文晩期の製塩土器から、能登の揚げ浜式は今も続く

もっと読む（学生・大人・ガチ・人物・出典）

②学生 海・浜バイオームで、横に水があり、真上に空が見えて雨が降っていないときだけ動く。1分で塩1個、塩8個ごとににがり1個。右クリックで受け取る（塩64・にがり16までためる）。煮つめ釜は大釜でも土器 [0-03] でもよい。

③大人 揚げ浜式：砂をしいた浜に海水をまき、天日で乾かす。塩のついた砂を海水で洗って濃い塩水（かん水）を取り、釜で煮つめる。能登では今もこのやり方が続いている。

④ガチ 日本では縄文晩期の製塩土器が見つかっている。江戸時代は瀬戸内の入浜式塩田（潮の満ち引きで海水を引き込む）がさかんだった。1972年からはイオン交換膜による電気透析で作るのが主流。
