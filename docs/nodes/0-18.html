本当の歴史

繊維をより合わせて長く強い綱にする。人類最古の撚りひもは、フランスのアブリ・デュ・マラで見つかった約4万1000〜5万2000年前の3本撚りのひも（長さ約6mm、針葉樹の樹皮の内側の繊維。ネアンデルタール人が作った。Hardy ほか 2020、Scientific Reports）。撚る向きを2段で変える作り方は今のロープと同じ。ゲームのロープは、リネンの糸（織物ノード、約1万年前）から作る

もっと読む（学生・大人・ガチ・人物・出典）

②学生 リネンの糸3つで作る（3本の糸を撚りあわせる）。のちに滑車やクレーンで重い物をつり上げるのに使う予定。

③大人 繊維を撚って糸にし、その糸を何本か「逆向き」に撚りあわせる。逆向きにすると、ほどけようとする力どうしがつり合って、ロープがほどけない。引っぱると撚りが締まり、繊維どうしの摩擦で力を分けあう。

④ガチ フランスのアブリ・デュ・マラ遺跡で、約4万1000〜5万2000年前の石器に、3本の撚った束をさらに撚りあわせたひもの切れはしがついていた（ネアンデルタール人、2020年発表）⚠️。古代エジプトではパピルスやヤシの繊維で太いロープを作り、大きな石を運んだ。
