紀元前4500年頃・生存・道具・Potter's wheel

へえ

①子ども 車輪より先に、焼き物を作る回転台（ろくろ）があった

②学生 けって速く回すろくろは「はずみ車の原理」（重い石の円盤に回転のエネルギーをためる）。

③大人 最古とされるろくろはククテニ・トリピリア文化（紀元前4500年ごろ）⚠️、ウルクの石のろくろは紀元前3129年ごろ。

④ガチ ウルクの絵文字の車は紀元前3500〜3350年、現物の最古級はリュブリャナ湿原の木の車輪（紀元前3130年ごろ）⚠️。日本のろくろは5世紀ごろ須恵器とともに。
