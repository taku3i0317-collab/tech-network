本当の歴史

銀を含む方鉛鉱から鉛を製錬 → 灰吹法（キューペレーション、紀元前3000年頃〜）：溶けた鉛に空気を当てて PbO にし、骨灰の皿に吸わせると銀だけ残る。1850 パークス法（亜鉛で銀を抜き出す）

②学生 銀の粒×9（インゴット1つ → 粒9つにも戻せる）。c:ingots/silver。

③大人 写真の感光材（臭化銀・ヨウ化銀）、鏡、電気の接点に使われてきた。

④ガチ 電気伝導率は全金属で一番（銅よりわずかに上）。それでも配線の主役が銅なのは、ずっと安いから。IC の配線もアルミ → 銅へ移ったが、銀はほとんど使われない。
