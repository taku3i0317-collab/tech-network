本当の歴史

GeO2+4HCl→GeCl4+2H2O。GeCl4 は沸点83℃の液体なので蒸留で他の塩化物から分け、水で加水分解 GeCl4+2H2O→GeO2+4HCl して高純度 GeO2 に

もっと読む（学生・大人・ガチ・人物・出典）

②学生 蒸留した GeCl4（沸点 約86℃）。水を加えて加水分解：GeCl4 + 2H2O → GeO2 + 4HCl で高純度 GeO2 になる。

③大人 1940〜50年代、イーグル・ピッチャー社やベル研究所はこの方法でトランジスタ用のゲルマニウムを作った：GeCl4 の蒸留 → 加水分解 → 水素還元 → 帯域精製。

④ガチ 今の GeCl4 は光ファイバーの原料でもある：SiCl4 と一緒に燃やして芯に GeO2 を入れ、光の屈折率を上げる。
