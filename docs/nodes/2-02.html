本当の歴史

木灰を水に浸して上澄み（灰汁＝あく）を取り、鍋で煮詰めると K2CO3（"pot ash"＝鍋の灰、potassium の語源）。古代から石けん・ガラスの原料。灰を使った最古級の記録は、紀元前2800年頃のバビロンの粘土の円筒に「灰を脂と煮た」とあるもの（石けんの最古の証拠と同じ記録 ⚠️、[2-09]）。シュメール・ギルスの粘土板には約4500年前に羊毛を洗った記録⚠️。これに消石灰を加えると K2CO3 + Ca(OH)2 → 2KOH + CaCO3↓（苛性化）で KOH ができ、古代〜中世の石けん作りでも使われた

もっと読む（学生・大人・ガチ・人物・出典）

②学生 原木をたき火にのせて30秒。木の中のカリウムやカルシウムが、燃えたあと炭酸塩・酸化物として残る。4個＋水バケツで灰汁。

③大人 灰は昔から畑にまく肥料で、洗剤でもあった。灰を溶かした水で布を洗ったり、山菜の「あく抜き」をしたりする。

④ガチ 木灰の主な成分は炭酸カルシウムと炭酸カリウム。炭酸カリウムは水によく溶けるが、炭酸カルシウムはほとんど溶けない。だから水に浸して上澄みを取ると、カリウムの塩だけを分けられる。
