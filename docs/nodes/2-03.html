本当の歴史

干上がった塩湖の蒸発岩。トロナ Na2CO3·NaHCO3·2H2O を加熱 2(Na2CO3·NaHCO3·2H2O)→3Na2CO3+CO2+5H2O。古代エジプトはナトロンをミイラ作り（最初の証拠は古王国第4王朝、紀元前2600年頃のヘテプヘレス1世の内臓箱）とガラスに使い、大プリニウス『博物誌』（77年）が記録

もっと読む（学生・大人・ガチ・人物・出典）

②学生 Na2CO3·NaHCO3·2H2O（天然ソーダ）。かまどで焼くと炭酸ナトリウム：2トロナ → 3Na2CO3 + CO2 + 5H2O（約150〜200℃で十分）。

③大人 古代エジプトでは紀元前2600年頃（第4王朝）から、トロナを含む天然ソーダ「ナトロン」で遺体を乾かしてミイラにした。ガラスやファイアンス（焼き物）にも使った。大プリニウス『博物誌』（77年）にナトロンでガラスができた話がある。

④ガチ ナトロンはアラビア語のナトルーンから来た言葉で、元素記号 Na（ナトリウム）もナトロンに由来する。「トロナ」もナトルーンから来たと考えられている。
