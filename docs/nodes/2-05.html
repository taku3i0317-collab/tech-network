[2-05] ルブラン法

1791年・化学・Leblanc process

へえ

①子ども 塩と硫酸からソーダを作る方法。出てきた塩酸のガスは、はじめ空に捨てられた

②学生 捨てていたガスを水に吸わせると、売れる塩酸になった。

③大人 ルブランは革命で工場を取り上げられ、貧しさの中で亡くなった。

④ガチ アルカリ法は、世界で最初の頃の公害を取りしまる法律の一つ。

本当の話

1791 ニコラ・ルブラン。2NaCl+H2SO4→Na2SO4+2HCl↑、Na2SO4+2C+CaCO3→Na2CO3+CaS+2CO2。HCl は当初垂れ流し→1863 英国アルカリ法（初期の大気汚染規制）で回収義務

前提（これが無いと作れない）

岩塩鉱・硫酸・石灰焼成・木炭

これを使って生まれた物

重クロム酸カリウム・苛性ソーダ・硫化水素と硫黄回収・ソーダ石灰ガラス
