本当の歴史

CaF2 + H2SO4 → 2HF↑ + CaSO4（副産物は石こう）。1771 シェーレが蛍石を硫酸で処理して「フッ素酸」を得た（ガラスのレトルトが侵食されたことで性質に気付いた）。工業では200〜250℃のロータリーキルン。HF気体を水に吸わせたものがフッ酸

もっと読む（学生・大人・ガチ・人物・出典）

②学生 蛍石1＋硫酸1（ガラス瓶は上に戻る）＋空の鉛の瓶かポリエチレンの瓶1 → フッ酸（その瓶入り）1＋石こう1（10秒、燃料1個で8回、電気なし）。出てくる気体を受け器の水に吸わせる：水バケツ1杯で4回（空のバケツは出口へ）。CaF2 + H2SO4 → CaSO4 + 2HF。

③大人 1771年、シェーレは蛍石を硫酸といっしょにガラスのレトルトで熱し、新しい酸を見つけた。レトルトのガラスが内側から溶けて曇ったことで、この酸がガラスを溶かすと分かった。だから工場の釜・管・瓶は鉛（のちにろう・ゴム・ポリエチレン）で作られた。

④ガチ 今の工場は、約200〜250℃のゆっくり回る長い窯（ロータリーキルン）で反応させ、出てきたフッ化水素を冷やして液にする。副産物の石こうは、1トンのフッ化水素あたり約3.6トンも出る。
