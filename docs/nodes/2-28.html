本当の歴史

1907 ベークランド（特許1909）。フェノール＋ホルムアルデヒドの縮合。酸触媒・フェノール過剰→ノボラック（熱で溶ける線状）

もっと読む（学生・大人・ガチ・人物・出典）

②学生 ノボラックの反応液をかまどで熱して作る。DNQ（感光剤）と混ぜるとポジ型フォトレジスト（[2-32]）。熱しても固まらない（くり返し溶かせる）。

③大人 ノボラックはフェノールが CH2 でつながった短い鎖。OH がたくさん残っているので、アルカリの水に少し溶ける。DNQ がこれを溶けにくくし、光が当たると逆に溶けやすくする＝ポジ型レジストのしくみ。

④ガチ 1970年代後半から、ノボラック/DNQ のポジ型レジストが IC 作りの主役になり、g線・i線の時代（線幅 約0.35μm まで）を支えた。
