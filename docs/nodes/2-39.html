本当の歴史

C6H12O6→2C2H5OH+2CO2。1857 パスツールが酵母の働きと証明、1897 ブフナーが細胞なしの抽出液で発酵（酵素の発見）。蒸留しても 95.6% で止まる（共沸）

もっと読む（学生・大人・ガチ・人物・出典）

②学生 発酵した液3＋石英の蒸留器（戻る）＋空のガラス瓶で作る。エチレン [2-36]・クロロホルム [2-38] の原料、溶剤。⚠ GHS：引火性・眼刺激性。

③大人 エタノール C2H5OH は水（100℃）より低い78℃で沸くので、蒸留で集められる。でも 95.6％ になると、液と同じ割合の蒸気が出る（共沸）ので、それ以上は蒸留では濃くならない。

④ガチ 100％ のエタノールを作るには、水だけを取る物（生石灰・モレキュラーシーブ）を使うか、ベンゼンなどを足して蒸留する。
