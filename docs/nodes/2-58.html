[2-58] 無水酢酸

1852年・化学

へえ

①子ども 酢酸2つから水を1つ取ると、もっと反応しやすい物になる

②学生 パーキンは18歳で紫の染料モーブを見つけ、のちにこの反応で香料クマリンを作った。

③大人 トルエンの名前は南米のトルーバルサムから。

④ガチ 酢酸ナトリウムの過冷却は、くり返し使えるカイロに使われている。

本当の話

CH3COCl + CH3COONa → (CH3CO)2O + NaCl

前提（これが無いと作れない）

酢酸・クロルアルカリ電解

これを使って生まれた物

ケイ皮酸

ゲームでの作り方（ウィキ）

三塩化リン・塩化アセチル・酢酸ナトリウム・無水酢酸・ケイ皮酸
