本当の歴史

フッ素を多くふくむ合成ゴム。ふつうのゴムがだめになる 200〜250℃でも長く使え、油や燃料・多くの薬品にも強いので、エンジンや化学工場の O リング（すき間をふさぐ輪のパッキン）に使われる。1957年にデュポンが「バイトン」として出した ⚠️（1958年とする資料もある）

もっと読む（学生・大人・ガチ・人物・出典）

②学生 CF3 の出っぱりが鎖をきれいに並ばせないので、プラスチックでなくゴムになる。

③大人 真空の装置の O リングは、ガスを出しにくいフッ素ゴムがよく使われる。

④ガチ 作るときにフッ化水素や塩素を使うので、工場では漏れを厳しく管理する。
