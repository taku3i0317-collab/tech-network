本当の歴史

管の中の少しの液体が、熱い側で蒸発し、冷たい側で凝縮して、細い芯（ウィック）を伝って戻ってくることで熱を運ぶ。1942年にゼネラルモーターズのゴーグラーが考えた（特許1944年）が使われず、1963年にロスアラモスのジョージ・グローバーが知らずに再発明して「ヒートパイプ」と名づけた。1960年代後半に NASA が人工衛星で育て、今はノートパソコンの CPU の熱を銅の管でファンまで運ぶ
