本当の歴史

1852年にケルビン卿（ウィリアム・トムソン）が、冷凍機を逆向きに使えば暖めるのにも使えると理論で示した。1856年、オーストリアの鉱山技師ペーター・フォン・リッティンガーが、エーベンゼーの塩の工場で、湯気の熱をくり返し使って塩水を煮つめる装置を作り始めた（真水ではうまく動いたが塩水では失敗し、1858年にやめた）。暖房のときは外の冷たい空気からも熱を集めて部屋へ運ぶので、使う電気より多くの熱を出せる。今のエアコンは四方弁で冷媒の向きを変えて冷房と暖房を切り替える
