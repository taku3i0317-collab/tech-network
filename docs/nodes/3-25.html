どうやって手に入れるか

炭化カルシウム（カーバイド）：レシピは無い（拾う・掘る・ほかの方法）

本当の歴史

1892 トーマス・ウィルソン（アメリカ、アーク炉でアルミを作ろうとして偶然）とアンリ・モアッサン（フランス）。CaO + 3C → CaC2 + CO（約2000℃）、水で CaC2 + 2H2O → C2H2 + Ca(OH)2。1t に約3000kWh

もっと読む（学生・大人・ガチ・人物・出典）

②学生 同じ年に、フランスのモアッサンも電気炉でカーバイドを作った（モアッサンは1906年にフッ素の単離でノーベル化学賞）。

③大人 カーバイドのアセチレンは、炭鉱や自転車のランプの明かりになり、酸素と燃やすと鉄を切るほど熱い炎になる。

④ガチ カーバイド1トンに約3000kWh の電気が要るので、工場は水力発電所のそばに建てられた。アセチレンは酢酸ビニル → ポリビニルアルコールなど化学品の出発点（KPR の材料）。
