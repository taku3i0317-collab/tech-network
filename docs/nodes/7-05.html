本当の歴史

1668 ニュートンの反射望遠鏡はスペキュラム合金（Cu:Sn≈2:1、反射率約60%、すぐ曇る）。1835 リービッヒの銀鏡反応、1857 フーコー（とシュタインハイル）がガラスに化学銀めっきした鏡（反射率90%超・再めっき可）。1930年頃 カリフォルニア工科大のジョン・ストロングがアルミ蒸着を開発（曇らない、紫外も反射。詳しい論文は1936年）

もっと読む（学生・大人・ガチ・人物・出典）

②学生 銅インゴット×2＋スズのインゴット×1 → 3個（スズ 約33%）。かまどで溶かすとスペキュラム合金。

③大人 ニュートンは銅6・スズ2に少しヒ素を加えた合金で、自分の望遠鏡の鏡を作った。配合は鏡職人それぞれの秘密だった。

④ガチ スズが3割をこえると、青銅は赤銅色から銀白色に変わる。Cu-Sn の金属間化合物（δ相など）が増えるためで、そのぶんとても固く、もろくなる。
