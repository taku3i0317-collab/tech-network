[7-20] エキシマレーザー

1975年・光学・Excimer laser

へえ

①子ども 「エキシマ」は「興奮したときだけくっつく二人組」という意味

②学生 最初の密着露光（1960年ごろ）はマスクをウェハーにじかに押し当てた。マスクがすぐ傷むので、1973年にパーキンエルマーのマイクラライン（等倍の投影、鏡を使う）、1978年に GCA の DSW4800（g線、10分の1に縮める最初のステッパー）が出た。

③大人 液浸は、レンズとウェハーのあいだを水（屈折率 1.44）で満たして NA を 1.35 まで上げた。

④ガチ EUV（13.5nm）はどんな物質にも吸われるのでレンズが作れず、多層膜の鏡で光を集める。

本当の話

希ガス+F2 を放電で励起すると、励起状態でだけ結合する ArF*/KrF* ができ、壊れるときに紫外線を出す。ArF のガスは Ar 数%・F2 約0.1%・残りの大半が Ne。1975 希ガスハライドエキシマレーザー発振、1982 IBM のカンティ・ジェインが露光に応用

前提（これが無いと作れない）

フッ素ガス・希ガス精製・空気分離・紫外光学材料・変圧器・PTFE

これを使って生まれた物

化学増幅レジスト・液浸光学・縮小投影露光
