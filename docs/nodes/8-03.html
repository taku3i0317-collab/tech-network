本当の歴史

1830〜40年代 ホイットワースが「3枚の板を互いにこすり合わせると3枚とも平面になる」方法で鋳鉄の定盤を作った。20世紀には花こう岩の定盤（さびず、温度で変形しにくい）

もっと読む（学生・大人・ガチ・人物・出典）

②学生 銑鉄×4＋砂 → 1枚。利き手にこの板、もう片方の手に別の板を持って右クリック → ルージュを1つ使って2枚をすり合わせる。2枚だけでは凸と凹のまま合ってしまう。3枚を A-B・B-C・C-A と順に合わせると、3枚とも平らになり、そりが 1µm 以下で定盤になる。

③大人 1830〜40年代、ホイットワースは「3枚の板を互いにすり合わせると、ほかの基準なしに3枚とも平面になる」方法を広めた。A と B が合い、A と C が合えば、B と C は同じ形。その B と C も合うなら、どちらも平らしかない。

④ガチ もっと平らな物がなくても、平らな物は作れる。ホイットワースは研磨剤ですり合わせるより、赤い塗料（光明丹）を付けてこすり、当たって色の付いた高い所を「きさげ」で少しずつ削る方法をすすめた。平面・直角・ねじ・物差しが、機械を作る機械（マザーマシン）の出発点になった。
