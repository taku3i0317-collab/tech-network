本当の歴史

アセチレンは押し縮めると爆発しやすく、そのままではボンベで運べなかった。1896年、フランスのジョルジュ・クロードとアルベール・エスが、アセチレンがアセトンにたくさん溶けて安全になることを見つけた。スウェーデンの AGA 社のグスタフ・ダレンは、ボンベの中に珪藻土などのすき間の多い詰め物（アガマッサン、1906年）を入れてアセトンを含ませ、さらに灯台の火を必要なときだけ点滅させる装置と、明るくなると自動でガスを止める「太陽弁」（1907年）を作った。これで灯台を人がいなくても何か月も動かせるようになった（1912年ノーベル物理学賞）。ダレン自身は1912年、実験中の事故で目が見えなくなった
