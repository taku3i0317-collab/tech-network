[I-28] X線回折と結晶構造解析

1912年・発見・考え方・X-ray diffraction and crystal structure analysis

へえ

①子ども 結晶に X 線を当てると、目に見えない原子の並びが点の模様になって写る

本当の話

1912年、ドイツのマックス・フォン・ラウエが、結晶に X 線を当てると、原子の規則正しい並びが細かい回折格子のように働いて、決まった方向に点の模様ができることを示した（1914年ノーベル物理学賞）。1913年、イギリスのブラッグ父子（ウィリアム・ヘンリーとウィリアム・ローレンス）が、その模様から原子の並び方と間隔を計算する方法を作り、食塩などの結晶の形を決めた（1915年ノーベル物理学賞）。1916年にはデバイとシェラーが、粉にした結晶でも測れる方法（粉末法）を作った（デバイは1936年ノーベル化学賞）。今もシリコンの結晶の向きを確かめたり、新しい物質の形を調べたりするのに使われる
