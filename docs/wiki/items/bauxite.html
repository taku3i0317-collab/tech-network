ボーキサイト

Bauxite・アイテム・Metallurgy

本当の歴史：[1-24] ボーキサイト（1821年）

説明

①子ども 赤茶色の土のような石。アルミニウムの原料。

②学生 アルミニウムの水酸化物（ギブサイト Al(OH)3 など）と、赤い鉄さび（酸化鉄）のまざりもの。ボーキサイトの鉱石を掘ると出る。水酸化ナトリウムで溶かしてアルミナを取り出す（バイヤー法 [1-14]）。

③大人 暑くて雨の多い土地で、岩が長いあいだ雨に洗われると、溶けやすい成分が流れ去り、アルミと鉄が残る（風化残留）。赤い色は鉄さびの色。

④ガチ 1821年、ベルティエが南フランスのレ・ボー村の近くで見つけ、村の名前から名づけた。今はオーストラリア・ギニアなどの熱帯・亜熱帯の国が大産地。
