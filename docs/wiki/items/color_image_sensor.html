色の分かる画像センサー

Colour Image Sensor・アイテム・Semiconductor

本当の歴史：[9-45] ベイヤー配列のカラーフィルター（1976年）

説明

①子ども 画像センサーの上にベイヤーのカラーフィルターを載せた素子。赤・緑・青を見分けられる。

②学生 画像センサー＋ベイヤーのフィルター。手に持つと1画素の電子の数（画像センサーと同じ）。カメラモジュールの材料。

③大人 今のスマホのカメラの素子は、数千万の画素の上に赤・緑・青のフィルターと小さなレンズ（マイクロレンズ）が載っている。

④ガチ フィルターで色を分けるので、1画素に届く光は約3分の1になる。暗い所に強くするため、裏から光を当てる裏面照射型（2009年ごろ〜）も作られた。
