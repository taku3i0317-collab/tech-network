説明

①子ども 氷のように白くすきとおった石。アルミニウムを作るときの「お湯」になる。

②学生 Na3AlF6。作業台で フッ酸3（鉛の瓶は戻る）＋水酸化アルミニウム1＋水酸化ナトリウム3 → 氷晶石1（6HF + Al(OH)3 + 3NaOH → Na3AlF6 + 6H2O）。ホール・エルー法 [1-29] の電解浴。

③大人 アルミナは約2050℃でないと溶けないが、約1000℃で溶けた氷晶石の中にはよく溶ける。だから約960℃で電気分解できる。これがホール・エルー法の一番のアイデア。

④ガチ 天然の氷晶石は、グリーンランドのイヴィグトゥートでしかまとまって取れず、1987年に掘りつくされた。今は全部化学で作る（この作り方）。⚠️ 合成の工業化の年は確かめていない。
