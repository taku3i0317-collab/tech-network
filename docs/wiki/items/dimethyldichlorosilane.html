ジメチルジクロロシラン

Dimethyldichlorosilane・アイテム・Vacuum

仮（まだ本物どおりでない所がある）

本当の歴史：[5-06] 油拡散ポンプ（1928年）

説明

①子ども ケイ素にメチル基2つと塩素2つが付いた液体。水に入れるとシリコーンになる。

②学生 シリコーンの反応器で 金属シリコン1＋塩化メチル2（銅の触媒）＋空のガラス瓶 → これ（直接法）。蒸留水と反応させるとシリコーン油＋塩酸。

③大人 Si + 2CH3Cl → (CH3)2SiCl2。1940年ごろ GE のロチョウと、ドイツのミュラーが別々に見つけた「直接法」。今もシリコーンの大部分はこの方法。

④ガチ 空気の湿気でも反応して塩化水素の白い煙を出す（GHS：炎・腐食性）。本物の直接法では、メチルトリクロロシランなどもできるので、蒸留で分ける。

作り方

金属シリコン塩化メチル×2◇copper ingot（バニラ）空のガラス瓶
→ シリコーンの反応器直接法・2,000 W・15 秒 →
ジメチルジクロロシラン
Si + 2CH3Cl → (CH3)2SiCl2（ロチョウ 1941〜45）

使い道

ジメチルジクロロシラン蒸留水
→ シリコーンの反応器加水分解・2,000 W・15 秒 →
シリコーン油塩酸
(CH3)2SiCl2 + H2O → シリコーン油 + 2HCl
