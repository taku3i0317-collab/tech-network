説明

①子ども ウェハーの上に、同じ向きの結晶の薄い層を気体から育てる炉。

②学生 電気 10kW。素のシリコンウェハー1〜8枚＋四塩化ケイ素1＋水素2＋ドーパント源1（B2O3＝p・リン＝n）→ エピ層付きのウェハー＋乾いた塩化水素4（30秒）。水素は隣のガスホルダーから。エピ層は酸化しても残る。　ドーパント源の代わりに四塩化ゲルマニウムを入れると、Si と SiGe を交互に3対重ねる（GAA [9-38] の材料）。

③大人 約1200℃ のウェハーの上で SiCl4 + 2H2 → Si + 4HCl。下の結晶の並びをまねて原子が積もる（エピ＝上に、タキシー＝並ぶ）。基板とちがう型・ちがう濃さの層を作れるので、1960年代のバイポーラ IC は p の基板の上に n のエピ層を育てた。

④ガチ 1960年にベル研がエピタキシャルトランジスタを発表し、速く切りかわるトランジスタができた。シーメンス炉で多結晶の棒を太らせるのと同じ反応を、単結晶の薄い膜で使っている。
