本当の歴史：[8-05] ゲージブロック（1896年）

説明

①子ども 長さがぴったり決まった鋼の小さな板の箱。何個か重ねると、好きな長さの物差しになる。

②学生 るつぼ鋼×4＋水バケツ（焼入れ）＋ルージュ（仕上げ）。空中で右クリック → 目標の長さを何個で作るか。左手にマイクロメータを持って旋盤を右クリック → 旋盤の狂いを ±1µm に合わせる（ノギスでは粗すぎる）。

③大人 1896年、スウェーデンのヨハンソンは、少ない数のブロックを組み合わせて何万通りの長さを µm の精度で作れるセットを考えた。ヘンリー・フォードが買い入れ、アメリカの工場の互換性部品を支えた。

④ガチ 表面が平らすぎて、押しつけて少しずらすと吸い付いて離れない（リンギング）。重ねても誤差がほとんど増えないので、組み合わせて使える。工場の測定具は、ゲージブロックと比べて合わせる。
