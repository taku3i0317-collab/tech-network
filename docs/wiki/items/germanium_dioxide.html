二酸化ゲルマニウム

Germanium Dioxide・アイテム・Metallurgy

本当の歴史：[1-01] 石炭灰からのゲルマニウム（1930年）

説明

①子ども ゲルマニウムと酸素がくっついた白い粉。

②学生 Ge精鉱＋硫酸（粗い・9Nまで）か、GeCl4 を水で分解（高純度・10Nまで）して作る。木炭か水素炉で還元するとゲルマニウムになる。

③大人 GeO2 は SiO2（石英）と同じ形の結晶をとる兄弟分。水素で還元する：GeO2 + 2H2 → Ge + 2H2O（約600〜700℃）。木炭でも GeO2 + C → Ge + CO2 で還元できるが、炭素が少し残る。

④ガチ GeO2 は光ファイバーの芯に混ぜられている。屈折率を上げて、光を芯の中に閉じ込めるためだ。GeO2 だけのガラスは赤外線をよく通すので、赤外線カメラのレンズにも使われる。
