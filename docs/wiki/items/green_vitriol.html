緑礬（りょくばん）

Green Vitriol・アイテム・Chemistry

仮（まだ本物どおりでない所がある）

本当の歴史：[2-43] ばん油（1300年）

説明

①子ども うすい緑の結晶。焼くと、とろりとした強い酸（ばん油）が出る。

②学生 黄鉄鉱を水の中で風化させて作る。＋石英の蒸留器（ガラスのレトルト、戻る）＋空のガラス瓶 → ばん油（硫酸）。ベンガラが作業台に残る。⚠ GHS：急性毒性（経口）・眼刺激性。

③大人 FeSO4·7H2O。焼くと 2FeSO4 → Fe2O3 + SO2 + SO3、SO3 を水に吸わせると H2SO4。

④ガチ インクの材料（没食子と混ぜて黒い「没食子インク」）にも使われ、中世の写本の多くはこのインクで書かれた。
