研削皿（鋳鉄）

Grinding Tool (Cast Iron)・アイテム・Optics

仮（まだ本物どおりでない所がある）

本当の歴史：[7-03] レンズ研磨（1650年）

説明

①子ども ガラスを砂でけずってレンズの形にするための鉄の皿。何度でも使える。

②学生 鉄インゴット×3。光学ガラスと砂といっしょに作業台に置くと、すりガラスのレンズ素材ができる（皿は戻る）。

③大人 17世紀のレンズ職人は、くぼんだ鉄や真ちゅうの皿の上で、水でぬらした砂やエメリー（コランダムの粉）でガラスをこすった。粗い粉から細かい粉へ、何段階も変えていく。

④ガチ 2枚の面をいろいろな向きにこすり合わせると、高いところから削れていき、自然に球面になる（球面だけが、どこでずらしてもぴったり合う形）。だから昔のレンズはほとんど球面だった。
