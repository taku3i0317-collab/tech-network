画像センサーの素子

Image Sensor Die・アイテム・Semiconductor

仮（まだ本物どおりでない所がある）

本当の歴史：[9-42] 画像センサー（1969年）

説明

①子ども 光を電子に変えて数えるチップ。手に持つと、その場の光で1画素にたまった電子の数が出る。

②学生 組立台：p-n 接合の板（フォトダイオード）＋NOT に合格したチップ（読み出し）＋アルミ（配線）＋ソーダ石灰ガラス（窓）。手に持つと画面の下に電子の数（明るいほど多い、満杯 6000 個で白飛び、±√N ばらつく）。カラーフィルター [9-45] を載せるとカメラの部品に。

③大人 フォトダイオードに光の粒（光子）が当たると電子が1つ生まれ、画素の中にたまる。光の粒は不規則に来るので数は ±√N ほどばらつく（ショットノイズ）＝暗い写真はざらざら。真っ暗でも熱で少し電子が出る（暗電流）。

④ガチ 1969年にベル研究所で CCD（電子をバケツリレーで送る）が考えられ、1993年ごろ NASA ジェット推進研究所のグループが画素ごとに増幅のトランジスタを持つ CMOS センサーを作った。スマホのカメラはほぼ CMOS。⚠️ 年は出典で確かめ中。
