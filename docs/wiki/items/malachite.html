Malachite・アイテム・Metallurgy

仮（まだ本物どおりでない所がある）

本当の歴史：[1-03] 銅の製錬（孔雀石）（紀元前5000年）

説明

①子ども 緑色の石。炭といっしょに焼くと銅が出てくる。

②学生 塩基性炭酸銅 Cu2CO3(OH)2。かまど（溶鉱炉なら速い）で銅インゴット。熱で CuO・CO2・H2O に分かれ、燃料の炭素（CO）が CuO から酸素を取る：CuO + C → Cu + CO。

③大人 セルビアのベロヴォデ遺跡では、約7000年前（紀元前5000年ごろ）に銅を製錬した跡（スラグ）が見つかっている。製錬にはマンガンを含む緑黒い銅の酸化鉱を使い、きれいな孔雀石はビーズにしていた。古代エジプトでは、すりつぶして目のまわりの化粧にもした。

④ガチ 孔雀石は約300℃で分解して黒い酸化銅になり、炭火の中の一酸化炭素で約800℃から還元が進む。銅の融点は 1085℃なので、溶かして固まりにするにはふいごで風を送る炉が要った。硫黄を含まないので、硫化鉱より簡単で、最初に使われた銅鉱石になった。
