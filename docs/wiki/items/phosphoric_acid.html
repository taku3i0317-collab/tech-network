リン酸

Phosphoric Acid・アイテム・Chemistry

仮（まだ本物どおりでない所がある）

本当の歴史：[9-25] 金属配線（1959年）

説明

①子ども とろりとした酸。チップのアルミの配線を形にけずるのに使う。

②学生 H3PO4（ガラス瓶入り、使うと瓶が戻る）。作業台で 骨灰1＋硫酸3＋空のガラス瓶2 → リン酸2。エッチング槽 [9-06] に入れると、現像したウェハーのアルミ（レジストのない所）だけを溶かす [9-25]。GHS：腐食性。

③大人 Ca3(PO4)2 + 3H2SO4 → 2H3PO4 + 3CaSO4。骨の灰（リン酸カルシウム）に硫酸をかけると取れる。2Al + 2H3PO4 → 2AlPO4 + 3H2 で、アルミは溶けるが、酸化膜とシリコンはほとんど溶けない。

④ガチ 1960年代の IC 工場は、リン酸に少しの硝酸と酢酸を混ぜた液を温めてアルミを削った。リン酸はコーラの酸っぱさ、肥料、さび取りにも使われる。
