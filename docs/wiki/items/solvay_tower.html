説明

①子ども 塩と石灰石からソーダを作る塔。中のアンモニアはぐるぐる回って、何度も使える。

②学生 鉄6＋ソーダ石灰ガラス＋銅ケーブル＋かまどで作る。5kW。塩2＋方解石（石灰石）1 → 炭酸ナトリウム1（15秒）。最初にアンモニア水を入れる（1本で4単位、空の瓶が出る）。アンモニアは回って戻り、失うのは16回に1単位だけ。副産物の塩化カルシウムの液は捨てる。

③大人 NaCl + NH3 + CO2 + H2O → NaHCO3↓ + NH4Cl（重曹は冷たい水に溶けにくいので沈む）。重曹を焼くと炭酸ナトリウム。NH4Cl は石灰で NH3 に戻す。全体では 2NaCl + CaCO3 → Na2CO3 + CaCl2 で、アンモニアは減らない。

④ガチ 1861年ベルギーのエルネスト・ソルベーが特許をとり、1865年に工場を動かした。塩酸ガスで大気をよごしたルブラン法に代わり、20世紀にはソーダのほとんどがこの方法になった。
