説明

①子ども タンタル石からタンタルを取り出す槽。入れた物で工程が切りかわる。

②学生 電気 3kW、1回20秒。①タンタル石1＋フッ酸2＋フッ化カリウム1 → K2TaF7（フッ酸の容器は戻る）②K2TaF7＋金属ナトリウム → タンタル（鉄の容器は戻る）。

③大人 ①マリニャック法：K2TaF7 は溶けにくく結晶になり、ニオブは液に残る。②K2TaF7 + 5Na → Ta + 2KF + 5NaF を鉄の釜で。できた塩は水で洗い流す。

④ガチ フッ酸は骨まで届く危ない酸なので、工業の材料としてだけ使い、鉛・ポリエチレンの容器で扱う（GHS：どくろ・腐食性）。槽は鉛で内張りする。
