説明

①子ども ガラスの元の液に、チタンの元の液を少しだけ混ぜたもの。

②学生 四塩化ケイ素×8＋四塩化チタン×1 → 8個。酸水素バーナーで超低膨張ガラス。⚠ GHS：腐食性（空気の湿気で塩化水素の煙が出る）。

③大人 コーニング社は合成石英と同じ炎の加水分解で、チタンを混ぜたガラスを作った（1960年代）。

④ガチ SiCl4 + 2H2O → SiO2 + 4HCl、TiCl4 + 2H2O → TiO2 + 4HCl。どちらも炎の中の水で酸化物の細かい粉になり、積もって固まる。
