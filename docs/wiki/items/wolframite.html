鉄マンガン重石（原石）

Wolframite・アイテム・Metallurgy

本当の歴史：[1-28] タングステン線（1910年）

説明

①子ども ずっしり重い黒い石。電球の線になる金属が入っている。

②学生 炭酸ナトリウムと混ぜてかまどで焼く（ソーダ融解）→ タングステン酸ナトリウム → 塩酸 → タングステン酸 → かまど → 三酸化タングステン → 水素炉 → タングステン粉 → タングステン線。真空管のフィラメントになる。

③大人 (Fe,Mn)WO4 + Na2CO3 → Na2WO4 + (Fe,Mn)O + CO2。Na2WO4 は水に溶けるので鉄・マンガンと分けられる。塩酸で H2WO4 を沈殿させて焼くと WO3、それを水素で還元する：WO3 + 3H2 → W + 3H2O。

④ガチ ドイツの鉱夫は錫を溶かすときにこの石が混ざると錫が減るので「狼の泡（Wolf Rahm）」と呼んだ。これが元素記号 W の由来。1783年、スペインのエルヤル兄弟がこの石から初めて金属タングステンを取り出した。
