仮（まだ本物どおりでない所がある）

本当の歴史：[B-20] 白色 LED バックライト（1996年）

説明

①子ども 青い光を当てると黄色く光る粉。白色 LED の材料。

②学生 化合物半導体の炉で 酸化イットリウム＋アルミナ＋酸化セリウム → 4（焼く）。青い LED と → 白色 LED。

③大人 イットリウム・アルミニウム・ガーネット（Y3Al5O12）に少しのセリウムを入れた物。セリウムが青い光を吸って黄色い光を出す。

④ガチ 1996年に日本の会社が、青色 LED にこの蛍光体を組み合わせた白色 LED を製品にした。
