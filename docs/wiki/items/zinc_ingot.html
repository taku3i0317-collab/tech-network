亜鉛インゴット

Zinc Ingot・アイテム・Metallurgy

本当の歴史：[1-13] 亜鉛（1150年）

説明

①子ども 亜鉛のかたまり。トタンや電池に使う。

②学生 閃亜鉛鉱をかまどで焼くか、反射炉で酸化亜鉛にしてからかまどで還元する。

③大人 ZnO + C → Zn + CO。でも還元に必要な約1000℃は亜鉛の沸点（約907℃）より高いので、亜鉛は気体で出てくる。空気に触れると燃えて酸化亜鉛に戻るので、空気を断って冷やして集める。

④ガチ 亜鉛の蒸留はインドのザーワル（12世紀ごろから19世紀初めまで操業）で始まり、ヨーロッパでは1738年にイギリスのチャンピオンが特許を取った。トタンは鉄に亜鉛をめっきしたもので、亜鉛が先にさびて鉄を守る（犠牲防食）。
